
# Personal Portfolio

Hi, I'm Simran Sethi, a first-year B.Tech student at Bosscoder School of Technology.
This is my personal portfolio website created as a Web Development project using HTML, CSS and JavaScript. It gives a short introduction about me, my education, skills, projects and interests.

## About the Project

The website is designed with a simple dark purple and black theme. It is responsive and includes interactive features to make it easy to use.

## Features

- Home section with introduction
- About Me section
- Education details
- Skills section
- Projects section
- Hobbies and interests
- Achievements section
- Contact information and form
- Dark mode and light mode
- Smooth scrolling navigation
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

portfolio/

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use Live Server for a better experience.
